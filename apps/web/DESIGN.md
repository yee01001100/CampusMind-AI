# CampusMind Web Design

## Scene

上午课间，学生站在有自然光的教学楼走廊，用一只手在手机上快速确认下一节课和截止事项。

## Direction

- Register: product
- Strategy: restrained
- Surface: pure white with a cool neutral utility rail
- Brand anchor: mineral teal `oklch(0.45 0.074 200)`
- Accent: clear amber for deadlines and uncertainty, never decoration
- Typography: one system sans family; compact fixed scale
- Motion: 150–220ms state feedback only; reduced-motion supported

## Component Rules

- Radius tops out at 16px for panels and 10px for controls.
- Use borders or a compact shadow, never both decoratively.
- Primary actions, current navigation and state indicators share one teal vocabulary.
- Loading uses skeletons; empty states teach the next action.
- Desktop keeps a fixed rail and readable content width; mobile uses a bottom navigation and single-column flow.
