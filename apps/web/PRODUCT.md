# Product

## Register

product

## Users

需要在课间、教学楼走廊或宿舍快速整理校园事务的在校学生。他们需要在几十秒内知道下一节课、最紧急任务和通知是否需要确认，而不是研究系统本身。

## Product Purpose

把分散的课程、通知、待办和校园资料收敛成可信、可确认、可执行的个人校园工作台。成功意味着学生能从“今天有什么事情”一路完成通知解析、人工确认、创建任务、查看提醒和带来源问答。

## Brand Personality

可靠、清醒、有分寸。表达直接友好，不夸大 Agent 能力，不把不确定信息伪装成事实。

## Anti-references

不做游戏化签到页、炫技型 AI 对话框、霓虹暗色控制台或充满装饰卡片的 SaaS 模板。不得展示内部推理、密钥或敏感日志。

## Design Principles

1. 先给学生今日结论，再给来源和细节。
2. 不确定信息必须显式确认，不能猜测。
3. 状态变化可见且可恢复，重要操作防重复。
4. 手机优先，但桌面上要提升并行阅读效率。
5. Agent 与 Tool 的状态要透明，内部实现要克制。

## Accessibility & Inclusion

目标为 WCAG 2.1 AA。支持完整键盘操作、明显焦点、语义化状态播报、减少动态效果，并避免只用颜色表达优先级或错误。
