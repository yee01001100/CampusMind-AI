# CampusMind AI 项目开发任务说明文档

## 一、项目名称

**CampusMind AI —— 基于Agent的私人校园智能体**

项目赛道：

Meoo 想天开——AI互动应用赛道

项目定位：

基于开源Agent框架DeepTutor（https://github.com/HKUDS/DeepTutor）进行二次开发，将原有AI学习辅助能力扩展为面向大学生校园生活的综合智能助手。

核心目标：

让AI成为学生进入校园生活的信息入口，通过Agent主动理解、整理和处理校园事务，实现：

- 校园信息自动整合
- 待办事项智能生成
- 课程提醒
- 校园知识问答
- 个性化学习生活辅助
- 主动式AI关怀


---

# 二、项目背景与痛点

## 当前校园问题

高校信息系统普遍存在：

1. 信息分散

学生需要访问：

- 教务系统
- 学院网站
- 通知公告
- 班级群
- 学校公众号

大量信息无法统一获取。


2. 信息复杂

学校通知通常：

- 内容长
- 专业术语多
- 学生难以快速理解重点


3. 缺少主动提醒

学生容易错过：

- 报名截止时间
- 考试安排
- 缴费事项
- 活动通知


4. 校园系统缺少智能化交互

传统系统：

用户主动寻找信息。


AI校园助手：

AI主动理解学生需求。

# 六、核心模块设计


# 1. Agent核心层

作用：

负责理解用户需求，并决定调用哪个Skill。


输入：

```
最近有什么事情？
```

Agent判断：

```
需要调用：

task_manager

notice_reader

calendar_skill

```


输出：

综合结果。


---

# 2. Campus Skill系统

新增核心模块。


目录设计：

```
campus_skill/

├── notice_reader

├── course_manager

├── task_manager

├── student_profile

└── campus_chat

```


---

# 3. 通知解析Skill


功能：

读取校园通知。

处理：

```
原始通知

↓

AI理解

↓

提取：

标题

时间

对象

重要程度

行动建议

↓

生成学生任务

```


示例：

输入：

```
关于2026年四六级报名通知
```


输出：

```
事项：

英语四六级报名


截止时间：

9月15日


建议：

立即完成报名
```


---

# 4. 课表管理Skill


功能：

管理学生课程。


数据格式：

```json
{
"name":"Java程序设计",
"time":"周三8:00",
"location":"教学楼302"
}
```


实现：

- 今日课程查询
- 上课提醒
- 空闲时间分析


---

# 5. Task任务管理Skill


功能：

自动生成学生任务列表。


例如：

输入：

```
学校通知+课程信息
```


生成：

```
今日任务：

[重要]
完成四六级报名

[普通]
提交Java实验报告

[提醒]
明天高数考试
```


---

# 6. Memory学生画像系统


保存：

```
学生专业

年级

课程

兴趣方向

历史任务

学习习惯

```


用于：

个性化回答。


例如：

计算机专业学生：

推荐：

- AI比赛
- 编程课程
- 科研项目


---

# 7. AI主动提醒系统


区别普通聊天机器人。


逻辑：

```
定时检测

↓

分析任务截止时间

↓

判断重要程度

↓

主动提醒用户

```


例如：

```
距离考试还有3天

根据你的复习情况：

建议今晚完成：

第一章复习
```
